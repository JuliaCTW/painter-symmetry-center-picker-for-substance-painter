# Vertex Symmetry Picker 1.0 Beta

Pick a real mesh vertex in an independent preview and copy its converted X/Y/Z symmetry offset into Adobe Substance 3D Painter.

在独立网格预览中选择真实顶点，复制换算后的 X/Y/Z 对称偏移到 Adobe Substance 3D Painter。

- [中文安装与使用说明](README_中文.md)
- [English installation and usage](README_English.md)

## Features / 功能

- Six orthographic views, wheel zoom, right-drag pan / 六个正交视角、滚轮缩放、右键平移
- Real vertex selection with a yellow marker / 真实顶点选取与黄色标记
- Six-decimal clipboard values / 六位小数复制
- Chinese and English UI / 中英文界面
- Runs alongside the earlier bounding-box center tool / 可与旧版包围盒工具共存

## Release / 版本

Plugin version: `1.0.0-beta1`. This share package preserves the exact code successfully tried by a user. Documentation has been updated to record that feedback; no new functionality was added.

插件版本：`1.0.0-beta1`。分享包保留用户试用成功的原始代码，仅更新说明中的测试反馈，没有增加新功能。

This remains a beta with limited compatibility testing. Z has not been independently verified in Painter. See the manuals for selection and geometry limits.

仍作为测试版分享，跨版本兼容测试有限，Z 轴未单独实测。选点与网格限制详见说明。

Independent third-party tool, not an official Adobe product. This package contains no Adobe software, SDK binaries, models, project files or activation data. Recipients need their own legitimate Painter installation and license.

独立第三方工具，非 Adobe 官方产品。包内不包含 Adobe 程序、SDK 二进制文件、模型、项目或激活信息。使用者需自行准备合法授权的 Painter。
