# 顶点对称定位工具 1.0 测试版

独立插件：`vertex_symmetry_picker.py`。可与原来的 Symmetry Center Picker 同时使用，不需要替换或停用旧工具。

## 安装
1. 在 Painter 的 Python 菜单打开 Plugins Folder（插件文件夹）。
2. 把 `vertex_symmetry_picker.py` 放进去，重启 Painter。
3. 在 Python 菜单启用 `vertex_symmetry_picker`，顶部可选择中文或 English。

## 使用
1. 点击「读取当前项目对象」，只勾选需要选点的身体或头部。
2. 在工具自己的预览里，放大并点击中线上的网格顶点。黄色圆点是选中的真实顶点，下方显示它的模型坐标。
3. 复制 X，打开 Painter 的 Mirror symmetry，Axis 选择 X，双击 Axis position X 的数字，Ctrl+A → Ctrl+V → Enter。Y/Z 请复制到对应轴。

## 预览操作
1. 滚轮：放大或缩小；右键拖动：平移。
2. 下拉菜单：切换正面、背面、两个侧面、俯视和仰视。六个固定正交视角，不支持自由旋转。
3. 「适应窗口」：重新居中并缩放到窗口范围。可以将工具面板浮动或拉大。

## 需要知道
- 在插件预览中点选，不是在 Painter 主视口中点选。预览不显示材质或纹理。
- 点击会吸附到附近 10 个界面像素内的真实顶点，不会生成一个任意表面点。放大并检查黄色标记，避免选到相邻顶点。点空白会清除选择。
- 点击坐标只用于寻找顶点，最终使用导出网格中该顶点的坐标，不从截图估算。
- 只对勾选几何体做遮挡判断。预览采用简化面绘制；相交面、非平面多边形、重叠几何体可能存在显示或选点歧义，建议隔离对象并切换视角检查。
- 顶点编号是本次导出 OBJ 的编号，不保证对应 Maya/Blender 的原始编号。
- 单个点只确定轴对齐平面的位置，不能确定倾斜平面的方向。必须自己选对中线顶点。
- 输出为 6 位小数，沿用已有工具的场景中心/radius 换算；Z 轴仍未在真实 Painter 中验证。
- 已完成本地真实 Qt 界面的选点、复制、语言切换和模拟项目检查；一位用户已在自己的 Painter 环境中试用并反馈正常。尚未做跨版本兼容测试，也未单独确认全部轴向。需要带 PySide6 的 Painter；此前基础工具测试环境为 Windows / Painter 12.0.3。
- 预览上限为 180000 个面角点（约 60000 个三角面）；超过时提示减少对象，不偷偷简化或改变顶点坐标。大模型读取与预览可能较慢。
- 重新导入网格后请重新读取。不会保存或替换原项目，不会修改网格或原生对称设置。读取时临时导出网格，正常结束会清理；异常退出可能留下临时文件。
